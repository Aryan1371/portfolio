# Personal Portfolio Website

A modern, responsive, and minimalist developer portfolio featuring dark mode by default, glowing accents, smooth micro-interactions, and mobile-friendly responsive layout.

## 🚀 Features

- **Hero Section**: High-impact introduction with dynamic typing text and prominent CTA buttons.
- **About Me**: Professional summary highlighting skills, experience, and background.
- **Projects Showcase**: Interactive project cards with category filters, live demo links, and GitHub links.
- **Skills & Tools**: Categorized skill tags across frontend, backend, tools, and soft skills.
- **Interactive Experience & Contact**: Clean contact form with validation, social links, and toast notifications.
- **Theme Switcher**: Smooth dark/light mode toggle with stored preference.

## 🛠️ Tech Stack

- **HTML5**: Semantic and accessible markup
- **Vanilla CSS3**: Custom design tokens, CSS variables, glassmorphism, responsive grid/flexbox
- **JavaScript (ES6+)**: Scroll animations, mobile navigation toggle, interactive filtering, and theme switching

## 💻 Local Preview

Simply open `index.html` in your favorite web browser or serve with any static web server:

```bash
# macOS
open index.html
```
